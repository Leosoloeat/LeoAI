## BROADCAST 06: Educational Series
> ใช้: ส่ง series ต่อเนื่อง 4 สัปดาห์

**สัปดาห์ 1:**
```
AI Tip ประจำสัปดาห์ 🤖

TIP #1: ทำไม AI ตอบ LINE แทนคุณได้

ลูกค้า 80% ถามคำถามเดิมซ้ำๆ:
"ราคาเท่าไหร่?" "มีโปรมั้ย?" "ส่งถึงไหน?"

ถ้า bot ตอบ 4 คำถามนี้ได้
คุณเพิ่งประหยัดเวลา 2-3 ชั่วโมง/วัน

สัปดาห์หน้า: ทำอย่างไรให้ bot ฟังดูเหมือนคนจริง
ติดตามได้เลยครับ

- Leo
```

**สัปดาห์ 2:**
```
AI Tip ประจำสัปดาห์ 🤖

TIP #2: วิธีทำให้ bot ฟังดูเหมือนคนจริง

เคล็ดลับคือ "System Prompt" ครับ
คือบทบาทที่คุณกำหนดให้ AI

แทนที่จะบอกแค่ "ตอบคำถาม"
บอกว่า "คุณคือ [ชื่อ] ผู้ช่วยของร้านเรา
พูดแบบเป็นกันเอง เหมือนเพื่อนคุยกัน
ลงท้ายด้วย ครับ เสมอ"

ผลลัพธ์ต่างกันมากครับ

สัปดาห์หน้า: วิธี setup ที่ไม่ต้องรู้ code เลย
ติดตามได้เลยครับ

- Leo
```

**สัปดาห์ 3:**
```
AI Tip ประจำสัปดาห์ 🤖

TIP #3: Setup LINE OA AI ใน 1 ชั่วโมง (ไม่ต้อง code)

3 ขั้นตอนหลัก:
1. สมัคร LINE OA + เปิด Messaging API
2. เขียน AI persona + FAQ ของธุรกิจคุณ
3. Deploy บน Railway (กดปุ่มเดียว)

ทุกอย่างมี tutorial ฟรีให้ทำตาม
ไม่ต้องจ้าง developer ครับ

สัปดาห์หน้า: KPI ที่ต้องวัดใน 30 วันแรก
ติดตามได้เลยครับ

- Leo
```

**สัปดาห์ 4:**
```
AI Tip ประจำสัปดาห์ 🤖

TIP #4: KPI ที่ต้องวัดใน 30 วันแรก

วัดแค่ 3 ตัวนี้พอครับ:

1. Response time เฉลี่ย (เป้า < 10 วิ)
2. % inbox ที่ bot จัดการได้ (เป้า > 70%)
3. Conversion rate (เทียบกับก่อน bot)

ถ้า 3 ตัวนี้ไม่ดีขึ้น → แก้ FAQ + persona
ถ้าดีขึ้น → ขยาย use case ต่อไป

4 สัปดาห์ที่ผ่านมา หวังว่าจะมีประโยชน์นะครับ
ถ้าอยากลองทำจริงๆ ทักมาได้เลยครับ

- Leo
```

## TIMING GUIDE

| วัน | เวลา | เหตุผล |
|---|---|---|
| จันทร์ | 9:00-10:00 | เริ่มสัปดาห์ มีแรงรับ content |
| พุธ | 12:00-13:00 | พักเที่ยง ช่วง peak engagement |
| ศุกร์ | 18:00-19:00 | เลิกงาน ผ่อนคลาย ใจเปิดรับ |

**หลีกเลี่ยง:** วันอาทิตย์เช้า, วันหยุดนักขัตฤกษ์ (ค่า engagement ต่ำ)

## A/B TEST IDEAS

- Version A: เปิดด้วย story / Version B: เปิดด้วย stat
- Short (5-7 บรรทัด) vs Medium (10-12 บรรทัด)
- CTA แบบ question vs CTA แบบ instruction
- Emoji หนาแน่น vs ไม่มี emoji
