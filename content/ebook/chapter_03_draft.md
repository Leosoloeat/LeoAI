## ทำไม LINE OA คือจุดเริ่มต้นที่ดีที่สุด

คุณอาจสงสัยว่าทำไมเราเริ่มที่ LINE ไม่ใช่ Facebook หรือ Website

เหตุผลง่ายมาก:

**คนไทยใช้ LINE**

ไม่ใช่แค่ "ใช้" — แต่ใช้ LINE เพื่อทำธุรกิจจริงๆ:
- 53 ล้านคนไทยมี LINE account
- SME ไทย 80%+ รับออเดอร์ผ่าน LINE เป็นหลัก
- ลูกค้าทัก LINE ก่อน IG หรือ FB 10 เท่า

แปลว่า — ถ้าคุณ automate LINE ได้ คุณ automate งานหลักของธุรกิจคุณ

## สิ่งที่ระบบ AI LINE OA ทำได้

ก่อนลงมือ ให้รู้ว่าเราจะสร้างอะไร:

**Bot ที่ทำได้:**
- ตอบคำถามลูกค้า 24/7 (ทุกคำถามที่คุณเขียนไว้ล่วงหน้า + ที่ไม่ได้เขียนไว้)
- รับออเดอร์และ confirm รายละเอียด
- บอกราคา โปรโมชั่น เงื่อนไข
- ส่งข้อมูล bank account / QR code
- นัดหมาย และส่ง reminder
- Escalate ให้คุณเมื่อสถานการณ์ซับซ้อน

**Bot ที่ทำไม่ได้ (และไม่ควรทำ):**
- ตัดสินใจเรื่อง exception ที่ซับซ้อน
- handle ลูกค้าโกรธแบบ de-escalate ได้สมบูรณ์
- replace ความสัมพันธ์ที่ต้องใช้ empathy ลึกๆ

ใน 90% ของสถานการณ์ LINE — bot ทำได้ครบ

## 5 ขั้นตอน: Setup ใน 1 วัน

> เวลารวม: ~2 ชั่วโมงถ้าทำต่อเนื่อง / 1 วันถ้าทำเป็น batch

---

### ขั้นที่ 1: สร้าง LINE OA Account (15 นาที)

ถ้ามีอยู่แล้ว — ข้ามไปขั้นที่ 2

1. เปิด [manager.line.biz](https://manager.line.biz) บนคอมพิวเตอร์
2. Login ด้วย LINE account ส่วนตัวของคุณ
3. กด "สร้าง Channel" → เลือก "LINE Official Account"
4. กรอกข้อมูล:
   - ชื่อ Account (= ชื่อธุรกิจ)
   - ประเภทธุรกิจ
   - ที่อยู่ / เบอร์โทร
5. ยืนยันอีเมล → Account พร้อมใช้งาน

**หมายเหตุ:** LINE OA ฟรี (Basic plan) เพียงพอสำหรับเริ่มต้น

---

### ขั้นที่ 2: เปิด Messaging API (20 นาที)

นี่คือส่วนที่ทำให้ bot เชื่อมต่อกับ LINE ได้

1. ไป [developers.line.biz](https://developers.line.biz)
2. Login → เลือก Provider ที่มีอยู่ (หรือสร้างใหม่)
3. กด "Create a Channel" → เลือก "Messaging API"
4. เลือก LINE OA Account ที่สร้างไว้
5. กด "Link" → Channel เชื่อมกัน

**เก็บข้อมูลสำคัญ 2 ชิ้น:**
- **Channel Access Token** (ใน Messaging API tab → กด "Issue")
- **Channel Secret** (ใน Basic settings)

> เก็บไว้ใน Notes หรือ password manager — จะใช้ในขั้นที่ 4

---

### ขั้นที่ 3: เขียน AI Persona (30-45 นาที)

นี่คือ "สมอง" ของ bot คุณ — สำคัญที่สุด

Bot จะตอบตาม persona ที่คุณเขียน ดังนั้นยิ่งละเอียด ยิ่งดี

**System Prompt Template:**

```
คุณคือ [ชื่อ bot] ผู้ช่วยของ [ชื่อธุรกิจ]

IDENTITY
โทน: เป็นกันเอง ฉลาด ให้ข้อมูล ไม่ hard sell
ภาษา: ไทยเป็นหลัก ลงท้ายด้วย "ครับ" หรือ "ค่ะ" เสมอ

PRODUCTS & SERVICES
[ชื่อสินค้า/บริการ 1]:
- รายละเอียด: [...]
- ราคา: [...]
- เหมาะกับ: [...]

[ชื่อสินค้า/บริการ 2]:
[ทำซ้ำตามจำนวนสินค้า]

PROMOTIONS (อัพเดทตามจริง)
- [โปร 1]: [รายละเอียด ระยะเวลา]
- [โปร 2]: [รายละเอียด]

FREQUENTLY ASKED QUESTIONS
Q: [คำถามที่ได้รับบ่อย 1]
A: [คำตอบ]

Q: [คำถามที่ได้รับบ่อย 2]
A: [คำตอบ]

[เพิ่มให้ครบอย่างน้อย 10 คำถาม]

HOW TO RESPOND
- ตอบสั้น 3-5 ประโยค ต่อ reply
- บอก value ก่อน price เสมอ
- จบทุก reply ด้วย 1 คำถาม หรือ soft CTA
- ถ้าไม่รู้คำตอบ ให้บอก "เดี๋ยวให้ทีมติดต่อกลับภายใน [X ชั่วโมง] ครับ"
- ถ้าลูกค้าโกรธหรือร้องเรียน ให้รับทราบ + แจ้งว่าจะให้ทีมติดต่อกลับ
```

**Tips สำหรับ System Prompt ที่ดี:**

1. **ยิ่ง specific ยิ่งดี** — อย่าเขียนว่า "ขายเสื้อผ้า" ให้เขียนว่า "ขายเสื้อผ้าผู้หญิง size S-2XL ราคา 290-890 บาท ส่งพัสดุ Kerry, Flash, J&T ค่าส่ง 50 บาทเต็มประเทศ"

2. **ใส่ FAQ จริงๆ** — เปิด LINE OA ของคุณแล้วดูว่า 10 คำถามที่ได้รับบ่อยที่สุดคืออะไร ใส่ทั้งหมด

3. **กำหนด "ไม่รู้บอก"** — ถ้าไม่ใส่ AI จะ "เดา" คำตอบ ซึ่งอันตราย

4. **ภาษาตรงกับแบรนด์** — ถ้าธุรกิจคุณเป็นกันเองมาก ให้ใส่ตัวอย่างประโยคที่อยากให้ bot พูด

---

### ขั้นที่ 4: Deploy Bot (20-30 นาที)

นี่คือส่วนที่ "เทคนิค" ที่สุด — แต่จะง่ายถ้าทำตาม step นี้

**Option A: ใช้ Template สำเร็จรูป (แนะนำสำหรับผู้เริ่มต้น)**

Template code ฟรีอยู่ที่: [github.com/leosoloeat/LeoAI/LeoSP]

ขั้นตอน:
1. ไป railway.app → Login ด้วย GitHub
2. กด "New Project" → "Deploy from GitHub repo"
3. เลือก repo → ตั้ง Root Directory: `LeoSP`
4. ใส่ Environment Variables:
   ```
   ANTHROPIC_API_KEY=sk-ant-...
   LINE_CHANNEL_ACCESS_TOKEN=[จากขั้นที่ 2]
   LINE_CHANNEL_SECRET=[จากขั้นที่ 2]
   ```
5. Deploy → รอ 2-3 นาที → ได้ URL

**Option B: ให้ Leo ทำให้ (ไม่ต้องทำเอง)**

ถ้าไม่อยากแตะ code เลย → [ลิงก์นัดคุยฟรี]

---

### ขั้นที่ 5: เชื่อม Webhook + ทดสอบ (10-15 นาที)

1. Copy URL จาก Railway (เช่น `https://your-app.railway.app`)
2. ไป LINE Developers Console → Messaging API tab
3. ใส่ Webhook URL: `https://your-app.railway.app/callback`
4. กด "Verify" → ต้องขึ้น "Success"
5. Enable "Use webhook"
6. Disable "Auto-reply messages" (ไม่งั้น LINE จะตอบทับ bot)

**ทดสอบ:**
- ทักหา bot ด้วย LINE ส่วนตัว
- ถามคำถาม 10 ข้อจาก FAQ ที่คุณเขียนไว้
- ถามคำถามนอก FAQ เพื่อดูว่า bot handle ยังไง
- ทดสอบ edge case: "ไม่พอใจ" "อยากคุยกับคน" "ลด/แลก/แจก/แถม"

## ตัวอย่างการสนทนาจริง

ต่อไปนี้คือตัวอย่างที่ bot ที่ตั้งอย่างถูกต้องควรทำได้:

```
ลูกค้า: "สวัสดีครับ มีขายอะไรบ้าง?"

Bot: "สวัสดีครับ! ยินดีต้อนรับ
ที่ร้านมี 3 อย่างหลักเลยครับ
[สินค้า A] [สินค้า B] [สินค้า C]
อยากรู้เรื่องไหนก่อนดีครับ?"

---

ลูกค้า: "ราคา [สินค้า A] เท่าไหร่?"

Bot: "[สินค้า A] ราคา [ราคา] ครับ
รวม [สิ่งที่ได้] แล้ว
ส่งฟรีเมื่อซื้อครบ [ราคา]
สนใจสั่งเลยมั้ยครับ หรืออยากรู้อะไรเพิ่มก่อน?"

---

ลูกค้า: "มีโปรอะไรบ้างตอนนี้?"

Bot: "ตอนนี้มีโปร [ชื่อโปร] ครับ
[รายละเอียดโปร]
โปรนี้ถึง [วันหมดอายุ] เท่านั้นนะครับ
สนใจสั่งได้เลยครับ บอกชื่อที่อยู่ได้เลย"
```

## KPI ที่ควรวัดสัปดาห์แรก

เมื่อ bot เปิดตัวแล้ว วัดตัวเลขเหล่านี้:

| KPI | วิธีวัด | เป้าหมาย |
|---|---|---|
| Response time | ดูใน LINE OA Insights | < 10 วินาที |
| Handled rate | % ที่ bot จัดการได้ไม่ escalate | > 70% |
| Escalation reason | ดู conversation ที่ escalate | ใช้ improve FAQ |
| Conversion rate | แชทที่กลายเป็น order | เทียบกับก่อน bot |

## ถ้า Bot ตอบผิด — ทำอย่างนี้

ทุก bot ตอบผิดบ้างในช่วงแรก — นี่เป็นเรื่องปกติและแก้ได้

**Process แก้ไข:**
1. เปิด conversation นั้น
2. ดูว่า bot ตอบผิดเพราะอะไร (ข้อมูลไม่มี / ข้อมูลผิด / เข้าใจคำถามผิด)
3. อัพเดท System Prompt ให้ครอบคลุม
4. Redeploy (2 นาที)

ทำสัปดาห์ละครั้งใน 1 เดือนแรก → bot จะเก่งขึ้นเรื่อยๆ

## ประมาณการ ROI (เดือนแรก)

สมมติธุรกิจขนาดกลาง รับข้อความ 100-300 รายการ/วัน:

**ก่อน bot:**
- เวลาตอบ LINE: 3-4 ชั่วโมง/วัน
- ตอบช้าเฉลี่ย: 45-90 นาที
- Missed inquiries ช่วงดึก: 20-30 รายการ/คืน

**หลัง bot:**
- เวลาที่คืนมา: 3-4 ชั่วโมง/วัน → ~90 ชั่วโมง/เดือน
- Response time: 2-5 วินาที ตลอด 24 ชั่วโมง
- Missed inquiries: 0 รายการ

**ถ้าธุรกิจคุณปิดดีลได้เพิ่มแค่ 5 deals/เดือน จาก response ที่เร็วขึ้น**

ที่ average order value ฿500 → เพิ่มรายได้ ฿2,500/เดือน
ที่ average order value ฿2,000 → เพิ่มรายได้ ฿10,000/เดือน

เทียบกับ setup cost ครั้งแรก ฿5,000-15,000

ROI = **คุ้มทุนภายใน 1-3 เดือน**
