# TikTok Script 05 — Myth Busting: ความเข้าใจผิดเรื่อง LINE OA AI
> Framework: Contrarian / Myth Busting
> Target: คนที่ skeptical / กลัวใช้ AI
> Duration: ~55-65 วินาที
> Type: Talking head พร้อม text overlay "MYTH vs FACT"

---

## SCRIPT

**[0-3 วินาที — HOOK]**
(Text overlay: "❌ MYTH vs ✅ FACT: AI ใน LINE OA")
"3 ความเข้าใจผิดที่ทำให้ SME ไทยยังไม่ใช้ AI — แก้ความเชื่อผิดได้เลยครับ"

**[3-40 วินาที — 3 MYTHS]**

Myth 1 (10 วิ):
"❌ 'AI ตอบไม่เหมือนคน ลูกค้าจะรู้'"
"✅ ความจริง: ถ้าตั้ง persona ถูก
bot พูดในโทนเดียวกับแบรนด์คุณ
ลูกค้าหลายคนไม่รู้ว่าคุยกับ AI"
(แสดง example conversation ที่ดูเป็นธรรมชาติ)

Myth 2 (10 วิ):
"❌ 'ต้องรู้ coding ถึงจะตั้งได้'"
"✅ ความจริง: ตั้งได้โดยไม่ต้องรู้ code
มี template สำเร็จรูป กรอกข้อมูลธุรกิจ
deploy กดปุ่มเดียว เสร็จใน 1 ชั่วโมง"

Myth 3 (10 วิ):
"❌ 'ถ้า bot ตอบผิดจะเสียลูกค้า'"
"✅ ความจริง: คุณตั้ง escalation ได้
ถ้าบอทไม่รู้ → บอก 'เดี๋ยวให้ทีมติดต่อ'
ไม่ตอบผิด — บอกว่าไม่รู้แล้วส่งต่อ"

**[40-55 วินาที — TRUTH + CHALLENGE]**
"ความจริงที่น่ากลัวกว่าคือ:
ทุกนาทีที่คุณไม่ตอบ LINE ลูกค้า
คือโอกาสที่หายไป — 24/7

bot ไม่ perfect แต่ perfect กว่า 'ไม่ตอบ'"

**[55-65 วินาที — ENGAGEMENT BAIT]**
"มีความเชื่อผิดเรื่อง AI อื่นอีกมั้ย?
comment มาได้เลยครับ อยากแก้ให้หมด"
