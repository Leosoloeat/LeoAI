# TikTok Script 01 — AI Automation Hook
> Framework: 5-Beat (Hook → Curiosity Gap → Escalation → Reveal → Engagement Bait)
> Target: เจ้าของร้านออนไลน์ / SME / freelancer
> Duration: ~45-60 วินาที
> Mood: สบายๆ เป็นกันเอง เหมือนเพื่อนเล่า

---

## VISUAL NOTES
- เปิดด้วยหน้าจอ LINE OA ที่มี notification ล้น (unread 200+)
- พูดตรงกล้อง ท่าทางปกติ ไม่ต้อง act
- ตัดไปหน้าจอ bot reply อัตโนมัติ
- จบด้วยหน้าจอ analytics / ยอดขาย

---

## SCRIPT

**[0-3 วินาที — HOOK]**
(กล้องจ่อหน้าจอ LINE notification 247 unread)
"คุณตอบ LINE ลูกค้า 3 ทุ่มอยู่มั้ย? ผมเคย — จนเจอวิธีนี้"

**[3-10 วินาที — CURIOSITY GAP]**
"3 ปีที่แล้วผมนั่งตอบ inbox ทีละคน
กลัวตอบช้า กลัวลูกค้าหาย
บางทีพิมพ์ผิดเพราะง่วง
จนคืนนึง... ผมลองทำอะไรบางอย่าง"

**[10-30 วินาที — ESCALATION]**
"ผมตั้ง AI ไว้ใน LINE OA ของธุรกิจผม
ใช้เวลาแค่ 1 วัน ไม่ต้อง code
คืนนั้นมีลูกค้าทัก 7 คน ตี 2
bot ตอบหมดทุกคน ผม... นอนหลับ"
(แสดงหน้าจอ LINE ที่ bot กำลัง reply)

**[30-45 วินาที — REVEAL]**
"ตอนนี้ bot ทำงาน 24 ชม. ทุกวัน
รับออเดอร์ ตอบคำถาม ส่งโปร
ผมดูแค่ดีลที่ bot ปิดไม่ได้
เดือนที่แล้ว bot ช่วยปิด 43 orders"
(แสดงตัวเลข orders หรือ dashboard)

**[45-60 วินาที — ENGAGEMENT BAIT]**
"ถ้าธุรกิจคุณยังตอบ LINE เอง ทุกวัน
comment 'ตอบ LINE' มาเลยครับ
เดี๋ยวมาเล่าให้ฟังว่าตั้งยังไง"
