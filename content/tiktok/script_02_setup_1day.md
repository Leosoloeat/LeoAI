## SCRIPT

**[0-3 วินาที — HOOK]**
(Text overlay ใหญ่บนหน้าจอ: "ตั้ง AI ตอบ LINE ใน 60 นาที")
"ใครอยากตั้ง AI ตอบ LINE อัตโนมัติ แต่กลัวยาก — ดูคลิปนี้ครับ"

**[3-15 วินาที — CURIOSITY GAP]**
"จริงๆ แล้วตั้งได้ใน 5 ขั้นตอน
ไม่ต้องรู้ code ไม่ต้องจ้าง developer
แค่มี LINE OA กับเวลา 60 นาที"
(Screen: LINE OA manager.line.biz)

**[15-50 วินาที — ESCALATION: steps]**

Step 1 (5 วิ):
"อันดับแรก ไป LINE Developers Console
สร้าง Messaging API — copy 2 key ออกมา"
(Screen: developers.line.biz → key copy)

Step 2 (5 วิ):
"ขั้นที่สอง เขียน AI persona ให้ bot
บอกมันว่าธุรกิจคุณขายอะไร ราคาเท่าไหร่
คำถาม FAQ ที่ได้รับบ่อย"

Step 3 (5 วิ):
"ขั้นที่สาม deploy บน Railway
กด New Project → GitHub → ใส่ keys
รอ 3 นาที — ได้ URL"
(Screen: railway.app)

Step 4 (5 วิ):
"ขั้นสุดท้าย ใส่ URL ใน LINE webhook
กด Verify → ผ่าน → เปิดใช้งาน"
(Screen: LINE webhook settings)

**[50-65 วินาที — REVEAL]**
(Demo: ทักบอท + บอทตอบ)
"ลองทัก — ตอบใน 2 วินาทีครับ
ถามราคา → ตอบ ถามโปร → ตอบ
ตี 3 ก็ตอบเหมือนกัน"

**[65-75 วินาที — ENGAGEMENT BAIT]**
"Template code ฟรีอยู่ที่ GitHub
comment 'ขอ link' เดี๋ยวส่งให้ครับ
ใครลองแล้วบอกด้วยนะครับ"
