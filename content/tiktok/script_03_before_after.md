# TikTok Script 03 — Before/After: ร้านขายของออนไลน์
> Framework: BAB (Before-After-Bridge) / Story
> Target: เจ้าของร้านค้าออนไลน์ผ่าน LINE
> Duration: ~45-55 วินาที
> Type: Talking head + text overlay + screen demo

---

## CONTEXT
ใช้ case study สมมติของร้านขายของออนไลน์ (อาจเป็น fictional composite)
ถ้ามีลูกค้าจริง — ขอ permission และใช้ชื่อจริงแทน

---

## SCRIPT

**[0-3 วินาที — HOOK]**
(Text overlay: "ก่อน vs หลัง: ร้านออนไลน์ + AI")
"ร้านขายของออนไลน์ LINE 200 ข้อความต่อวัน
ก่อนใช้ AI vs หลังใช้ AI — ดูตัวเลขนี้ครับ"

**[3-18 วินาที — BEFORE]**
(Screen: inbox เต็ม / notification ล้น)
"ก่อน: ตอบ LINE ทุกวัน 4-6 ชั่วโมง
ช่วงดึกมีทักเข้า 30-40 ข้อความ
ตื่นเช้ามาตอบค้าง — ลูกค้าบางคนไม่รอแล้ว
เสียไปประมาณ 5-10 orders ต่อสัปดาห์"

**[18-35 วินาที — AFTER]**
(Screen: bot กำลัง reply / analytics)
"หลังตั้ง AI LINE OA:
ข้อความ 80% bot จัดการได้เอง
response time จาก 45 นาที → 2 วินาที
missed orders จาก 5-10/สัปดาห์ → เกือบ 0
และเจ้าของร้านนอนหลับปกติครับ"

**[35-45 วินาที — BRIDGE]**
"สิ่งที่เปลี่ยนคือแค่:
ตั้ง AI ใน LINE OA ด้วย Gemini API
เขียน persona + FAQ ให้ครบ
deploy บน cloud — 1 วัน งานเสร็จ"

**[45-55 วินาที — ENGAGEMENT BAIT]**
"ธุรกิจของคุณตอบ LINE กี่ชั่วโมงต่อวันครับ?
comment มาได้เลย อยากรู้ว่าเยอะกันแค่ไหน
และถ้าสนใจ ลองดูว่าธุรกิจคุณ automate ได้ไหม"
