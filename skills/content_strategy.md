# Skill: content_strategy

## Purpose
Build a content strategy for a clinic or business — pillars, schedule,
formats, hooks, and a 30-day plan outline.

## Extract from input
- Platform(s): TikTok / Facebook / Line OA / IG / YouTube
- Target audience (age, gender, concern, location)
- Business goal (awareness / leads / retention / upsell)
- Current content sample if provided
- Budget or posting frequency constraint

## Content pillars framework (clinic/beauty)
1. Education — explain treatments, ingredients, conditions (builds trust)
2. Transformation — before/after, results, testimonials (social proof)
3. Behind the scenes — team, process, day-in-life (humanizes brand)
4. Offer / Promo — limited deals, packages (drives action)

## Platform-specific format rules
- TikTok: hook in 3s, 30–60s, trending audio, text overlay
- Facebook: 1200×628 image or 9:16 video, strong headline, minimal text
- Line OA broadcast: short copy, 1 clear CTA, best time 7–9am or 7–9pm
- IG Reels: 9:16, 15–30s, caption under 150 chars
