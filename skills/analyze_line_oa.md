# Skill: analyze_line_oa

## Purpose
Analyze Line OA account health from screenshots or pasted stats.
Score engagement and flag underperforming areas.

## Extract from input
- Total friends / followers
- New friends added (period)
- Block rate / unfriend rate
- Broadcast open rate and click rate
- Chat response rate and response time
- Active users / message volume

## Benchmarks (Line OA, Thailand market)
- Block rate: healthy < 5%, warning 5–10%, critical > 10%
- Broadcast open rate: good > 30%, average 15–30%, poor < 15%
- Chat response rate: good > 80% within 1hr
- Friend growth rate: healthy > 5%/month
